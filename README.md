# Vestígio

Assistente de análise forense para o [IPED](https://github.com/sepinf-inc/IPED). Ele instala e configura o IPED sozinho e conduz o analista num painel local. Também traz IA local com auditoria via MCP, análise financeira (RIF/SIMBA) e relatórios no modelo de qualquer instituição de segurança.

Este repositório só distribui os pacotes de instalação. O código-fonte é privado.

## Baixar

Baixe a versão mais nova em **[Releases](https://github.com/marcusvlessa/vestigio/releases/latest)**:

- Windows: `iped-pcba-windows.zip`. Extraia e dê dois cliques em `Vestigio.exe` (ou `instalar.bat`).
- Linux: `iped-pcba-linux.tar.gz`. Extraia e rode `scripts/instalar.sh`.

Depois de instalado, o painel se atualiza sozinho a partir daqui.

## Autorização de uso

O Vestígio só funciona nas máquinas autorizadas pelo responsável, e cada versão nova precisa de uma renovação. Na primeira vez, o painel mostra a tela **Autorização de uso**. Lá você gera um código de pedido, envia ao responsável e, depois, cola o código de autorização que receber.
